# Validación del prototipo – LIZCAR'S

## 1. Métodos de validación Lean UX

| Método | Descripción | Aplicación |
|---|---|---|
| Prueba de usabilidad | El usuario utiliza el prototipo mientras se observa su experiencia. | Permite identificar dificultades al utilizar la página web. |
| Mago de Oz | El usuario cree que una función es automática, pero una persona la realiza manualmente. | Permite evaluar funciones antes de desarrollarlas completamente. |
| Test A/B | Se comparan dos versiones de una solución. | Permite identificar cuál versión funciona mejor. |
| Prueba de 5 segundos | Se muestra una interfaz durante cinco segundos y se pregunta qué entendió el usuario. | Permite evaluar si la información es clara. |
| Puerta falsa | Se presenta una función que todavía no existe para medir el interés del usuario. | Permite conocer qué funciones podrían ser útiles. |

## 2. Método seleccionado

Se seleccionó la prueba de usabilidad porque la solución propuesta para LIZCAR'S consiste en una página web para gestionar el inventario. Este método permitirá observar cómo el gestor de bodega interactúa con el sistema e identificar posibles dificultades.

## 3. Plan de validación

**Hipótesis:**

Creemos que el gestor de bodega podrá mejorar el control de las existencias si utiliza una página web para registrar y consultar los movimientos de los repuestos.

**Usuario:**

Gestor de Bodega de LIZCAR'S.

**Actividad:**

Cuando el prototipo esté disponible, se le pedirá al usuario que interactúe con sus funciones principales y explique si le parecen claras y fáciles de utilizar.

**Métricas:**

- Facilidad de uso.
- Claridad de la información.
- Dificultades encontradas.
- Opinión y sugerencias del usuario.
