2. Contexto del proceso

LIZCAR’S es una empresa dedicada a la compra y venta de repuestos para carros.

Actualmente, el gestor de bodega registra manualmente las entradas y salidas de los repuestos mediante Excel. Esto puede generar dificultades para conocer con exactitud las cantidades disponibles en el almacén.

Entre los problemas identificados se encuentran la dificultad para conocer las existencias reales y la posibilidad de perder tiempo buscando repuestos. Además, se pueden presentar diferencias entre las cantidades registradas y las existencias físicas.

Cuando se encuentran estas diferencias, se revisan los registros anteriores y se realiza un conteo manual para verificar las cantidades.

4. Resultados


Hallazgo principal preliminar:

El gestor de bodega necesita gestionar correctamente el inventario de LIZCAR’S porque el registro manual mediante Excel dificulta conocer con exactitud las cantidades disponibles de los repuestos. Esto puede ocasionar pérdida de tiempo al buscar mercancía y obliga a revisar registros y realizar conteos manuales cuando existen diferencias entre las cantidades registradas y las existencias reales.

Este hallazgo es preliminar y deberá contrastarse con las respuestas obtenidas durante la entrevista.
